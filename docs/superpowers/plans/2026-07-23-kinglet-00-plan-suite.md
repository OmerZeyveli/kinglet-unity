### 0U state after the Linux execution pass (2026-07-28)

`gate 0U` exits **1**, and that is the accurate reading, not a defect to fix. Of the 27 frozen cells:

- **8 closed on Linux** — `filesystem-only`, `same-project-headless`, `isolated-headless`,
  `collision-refusal`, `mismatched-editor`, `cancellation`, `orphan-cleanup`, and
  `bridge-not-ready`, each backed by a published record under
  `docs/research/platform-spike/evidence/unity/execution/`.
- **1 inconclusive on Linux** — `live-editor-mcp.route`. A confirmed plan-level defect blocks it:
  the EditorPrefs a batchmode configure pass writes never become visible to a subsequently launched
  Editor, so no Editor has ever registered with the pinned MCP bridge on this host. The record
  carries that reason; it was escalated, not worked around.
- **18 missing** — every Windows 11 and macOS 26 cell. Those hosts exist and are the user's to run;
  no evidence for them may be produced from Linux. `spikes/platform/unity/run-host.sh` is the native
  entry point for macOS. **There is no `run-host.ps1`:** it could not be executed by its author, and
  an unrun script that launches Unity on someone else's machine is a liability rather than a
  deliverable.

`docs/research/platform-spike/reports/unity-execution.md` renders the same table with the open
cells' reasons, regenerated by `python3 -m tools.kinglet_spike unity-report --repo-root .`.

design and this suite are authoritative.

## Shared execution rules

- Use an isolated worktree created at execution time.
- Implement each plan test-first and commit at its task checkpoints.
- Never commit `.kinglet/local/`, `.research/`, raw prompts, credentials, account identifiers, or
  absolute user paths.
- Do not rewrite the existing `tools/kinglet_build/` implementation during Subproject 0.
- A native run means a native process on the target operating system; cross-compilation is not a
  runtime pass, and Windows runs may not use WSL or Git Bash.
- A failed or inconclusive candidate, host, route, or client result remains visible evidence.
- Runtime selection and any change to the fixed scoring rubric require explicit user approval.

## Completion boundary

This suite ends with evidence and approved architecture decisions. It does not build the production
Kinglet runtime, migrate the content inventory, or publish an end-user plugin.
